# Crit 5 reflection

**What was the breakthrough that moved the work forward?**

The breakthrough came when I stopped trusting completed tasks and green checks
and manually tested the game myself. I found disconnected features and visuals
that were too static and plain, so I created a new plan with reference links and
rebuilt it; however, I was still not fully satisfied because the design skills
and plugins I used did not completely fit the project, while limited tokens
reduced further iteration. This showed me that I need to evaluate each tool's
scope earlier and find a more token-efficient workflow.

**What did this work change about who I want to be as a software developer?**

This work taught me that a software developer still needs personal taste and
strong knowledge of web-game development, even when working with AI. I want to
expand my computer-science and design vocabulary so I can describe problems
more precisely and give agents clearer instructions.
